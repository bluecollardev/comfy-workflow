## 2026-10-24 (import adapters)

### A package folder goes into ComfyUI-Shared through an adapter (branch `feature/import-adapters`; `docs/ADR-008-import-adapters.md`, `docs/IMPORT-ADAPTERS.md`, `docs/PLAN-IMPORT-ADAPTERS.md`)
- Lucas: "i want to have a package uploader tailored to that spec. imports should have adapters ... AI to write adapters (mjs) that can be hot loaded". **An adapter is an `.mjs` that plans; the app applies.** `detect()` and `plan()` run in a child of the app's own executable under Node's `--permission` (read access to the source folder only; no writes, no child processes; the network is not blocked). Its ops are data, checked (no `..`, no absolute paths, only `input/ workflows/ models/ node-packs/`, source links cannot lead out) and applied by `libs/core/src/imports.ts`: copy (cloned where the disk can, sha256 checked first), link, verify, note, placeholder; never deletes; a differing existing file is a conflict unless Replace is on; dry run first; a record of each import.
- **Built-in adapters:** `comfy-shared` and `panama-imax-redux` (Kyle's delivery packages: `comfy/input` to `input/` unchanged, workflows to `workflows/panama-imax-redux/<round>/`, packs to `node-packs/panama-imax-redux/<pack>/`, everything else left in place; each copy carries its manifest hash). **Yours** are `*.mjs` in `~/.config/runpod-pod-manager/adapters/`, listed with their sha256 and used as saved (always fenced). **No approval step** (Lucas: "we don't need an approve"); the control is that nothing is a black box.
- **No-spend mode is hooked up end to end** (Lucas: "in settings, no spend mode doesn't seem to update no spend mode in header"): saving or clearing the Default Configuration now sets the header's badge at once and reloads the pod list (simulated pods replace real ones, or the other way round), where before it waited for the next refresh. When the environment forces it (`RUNPOD_DRY_RUN=1`, as `./start.sh desktop` does if you set it) the switch is locked with the reason, because it cannot turn it off; the app shows what the core says (`dry_run_forced`). The tab and section in Default Configuration are called **Import Adapters**.
- **Configuration > Environment can load defaults from the image or the Dockerfile**, as the Create Pod form does (Lucas: "we can do that from Create Pod form, but not from the pod card config button"): a **Load defaults** menu (From the image, From the Dockerfile), a Replace existing values switch and a summary, in the Default Configuration and in a pod's own Configuration (the card's Config button). The env and the build ARGs both become rows; an ARG is marked ARG and is stored with the env (an ARG reaches the pod as an env var anyway, and an explicit env var wins). Your values are kept unless Replace is on; loading twice adds nothing. Specs in the browser suite for both panels and in the real app against the repo's Dockerfile.
- **The Adapter Studio** (ADR-009, ADR-010): Edit, New adapter, Duplicate and Write an adapter with Claude are now one full-screen IDE-style modal with the app's mark and name in its header. Explorer (adapters, and the attached package as a tree marked with what the adapter does with each file), a CodeMirror editor with tabs for the code, the **prompt** (editable text) and a read-only viewer for the package's files, **Code / Preview / Split** as icon buttons, Problems and a status bar, and **the chat with Claude on the right: the chat builds the prompt, the prompt builds the adapter**. Claude works through eleven tools that write only `adapters/<id>.mjs` and `<id>.prompt.md` (hostile calls refused; the real-app spec checks the disk). Built-ins are editable by an override with Reset; adapters have a display name and an id; **every adapter carries a documentation header** (a rule on generation, enforced by the structure check, plus a Document action); **Save is explicit** (no autosave; autosave with versions is a todo) and runs the agent's check, up to three fix rounds. Replaces the preview-and-send modal, the draft panel, the textarea editor and Inspect (the button is Edit). Below 992 px (phone, portrait tablet, narrow window) the Studio's buttons are icons only, the name and the id stay side by side, (labels hidden, names kept for screen readers and tooltips) and its header wraps so every button is reachable. A **line wrap** toggle in the Studio's header (icon button, on by default, remembered, applies to the code, the prompt and the viewer). Default Configuration is tabs on a wide screen and a flow on a narrow one; a dismissible alert keeps its close icon inside it.
- **The rule: the app's Claude writes adapters and nothing else** (Lucas): a reply becomes at most one file, `<adapters>/<id>.mjs`, the id chosen by the app and never taken from the reply; extra code blocks, file names and commands are dropped and counted (the draft says so); no module means nothing written; a description is never stored. Enforced in `imports.draft`/`save`, tested by comparing the folder tree before and after a hostile reply.
