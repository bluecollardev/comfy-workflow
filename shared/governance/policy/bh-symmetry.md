# BH symmetry policy
Same shape everywhere. Only the contents differ.
1. Every shot folder has the same eight subfolders (see naming.md).
2. Every graph has the same lettered boxes in the same order: 00 read first and change report, A input, B lead assets or clean plate slots, then the processing boxes, then the handoff. A note at the top of every box, a preview after every stage.
3. Every shot has an inbox entry before it has a folder, and a tracker row after.
4. Both eyes use the same layers. Hero eye generates, the second eye follows by measured disparity. In a conversion pipeline the mono 2D prime is the LEFT eye (decided 2026-10-09). For corrosion, a comp element, the choice does not change the result. Only grain is per eye.
5. Every shot type uses the same names for the same things.
A new shot type copies the corrosion template and changes only what the picture needs.
