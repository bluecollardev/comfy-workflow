# Colour
Plates: DPX 2.0 BE, 4096x2160, RGB 10-bit packed, printing density.
Cineon log to linear: reference white 685, reference black 95, gamma 0.6. Stated on every Read node, never guessed. The DPX header is reported next to it.
Comp in scene-linear float: plate*(1-m) + fill*m.
One global CDL per shot, the same in both eyes (identity until Brynley sets it).
Painted fills and mattes carry plate-coded values. Soft matte values are the creative grade and are used exactly.
