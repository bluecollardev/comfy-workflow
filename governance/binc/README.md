# CANALV2
One place for everything, one place to find everything.

| Folder | What it holds |
|---|---|
| 00_POLICY | the rules. One page each. Start with 00_READ_ME.md |
| 01_GOVERNANCE | how work is run: workflow rules, sign-off, change log, delivery schedule |
| 02_SCRIPTS | the node pack, the graph slug builder, the collector |
| 03_INBOX | one folder per shot or request assigned to us. Nothing starts without an entry |
| 04_TRACKER | the work tracker (plain CSV) and the attention list |
| 10_CORROSION, 20_STEREO, 30_CREATIVE, 40_TITLES, 50_RND | the shots, by type. Every shot folder has the same shape |
| 90_DELIVERIES | only what has gone out, versioned |
| 99_ARCHIVE | superseded work. Nothing is ever deleted |

Official deliverables are recorded in the BH console, in Slack and in the panama-console repo. This tree is our working layer.
Where our tracker and the official record disagree, the official one wins and we fix ours.
