# Naming
- Simple, hierarchical, common sense. A file's name alone says what it is.
- Shot folder = the name the client uses: lowercase, hyphen. corrosion-051, enhance-141, archival-080a.
- Folders: lowercase, hyphens, no spaces, no trailing spaces, no punctuation.
- Working files: <shot>_<what>_<detail>_v###.<ext>   e.g. corrosion-051_hull-matte_lead-a_v003.png, corrosion-051_graph_v001.json
- Eye is spelled out: left, right. Frame numbers are padded as served.
- Dates only in reports, logs and request folders: 2026-10-09. Request folders are <yyyy-mm-dd>_<topic> so they sort by arrival.
- NO uuids, hashes, seeds, prompt ids or tracker numbers in any file name.
  Rule: a number that identifies the thing to a person goes in the name. A number that only identifies it to a machine goes in a sidecar.
- Sidecar: <filename>.meta.json beside the file (seed, model, prompt, checksum, source link, who, when).
- Shot folder shape:  00_READ_ME.md | 01_ASK | 02_SOURCE | 03_WORK | 04_GRAPH | 05_TEMPS | 06_REVIEW | 07_DELIVER
