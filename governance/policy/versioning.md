# Versioning
Versions only go up: v001, v002 ... The current version is stated in the shot's 00_READ_ME.md, never by renaming.
Nothing is overwritten. A last known good is never replaced. Superseded work moves to 99_ARCHIVE (copy first, then the original is left where it was unless Brynley says otherwise).
Approved or locked versions are marked in 00_READ_ME.md and tagged in git.
Graph revisions carry a CHANGE REPORT note (contract section 17).
