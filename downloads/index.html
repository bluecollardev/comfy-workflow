RunPod Manager

Start, stop and sync ComfyUI pods on RunPod.

Latest version

macOS Windows Linux

Your system is highlighted when it is detected. A greyed button means there is no build for it yet.

First time

  • macOS (Apple Silicon), easiest: download from Terminal, which macOS does not flag, so there is no warning at all: 
    curl -L -o ~/Downloads/RunPod-Manager.dmg https://github.com/bluecollardev/downloads/releases/latest/download/RunPod-Manager-mac-arm64.dmg && open ~/Downloads/RunPod-Manager.dmg
    then drag the app to Applications.
  • macOS (Apple Silicon), if you downloaded it with the button: open the DMG and drag the app to Applications. The app is not signed yet, so macOS blocks the first launch (right-click, Open no longer works on macOS 15 and later). Do one of these, once:
    • In Terminal: xattr -dr com.apple.quarantine "/Applications/RunPod Manager.app", then open the app.
    • Or open the app, close the warning, then go to System Settings, Privacy & Security, scroll to the message about RunPod Manager and click Open Anyway (it asks for your password).
  • Windows: run the installer; if SmartScreen warns, choose More info, then Run anyway (not signed yet).
  • Linux: make the AppImage executable (chmod +x) and run it, or install the .deb.
  • In Default Configuration, enter your RunPod API key.
  • On RunPod, add an SSH public key (Settings → SSH Public Keys) and a Container Registry Auth login for ghcr.io, then paste its ID in Default Configuration. Steps.
